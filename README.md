# KonsoleConnect

> Some goofy ahh terminal messages app idk.

KonsoleConnect is a random side project I made because discord wont add custom statuses

I am sure my messages there are getting stored on a server... I mean so are these but... yk.

## Planned Features

* Direct messages (obv)
* Small group chats
* Custom presence statuses
* Custom status messages
* Notifications
* Message history up to 24 hours

### Presence

omg this is the main thing. Since discord has like 4 of these I did my own thing:

```text
🟢 Online
🔵 Quiet
🟡 Away
🟣 Sleeping (with optional message blocking)
🔴 Do Not Disturb
⚫ Invisible
```

And Custom like:

```text
🟠 Lagging - Doesn't have the best signal
```

* Quiet means notifications are still enabled, but the user would not like to chat.
* Sleeping means... well... the user is asleep and may not receive notifications

## The Allegations (probably)

I am intentionally NOT trying to become another Discord gng.

I do NOT plan to add:

* Communities / guilds / servers / whatever you call them
* Voice calls
* Video calls
* Screen sharing
* Bots
* Complex permission systems
* Social feeds
* One quadrillion settings

The goal is to be simple (like me)!
